# game-site-backend-service ecosystem

This project is an ecosystem consisting of an arcade game built with Python, a web-site built with Flask and a lightweight backend-service in Go created in order to provide fast and secure operations between the database, the web-site and the game

## Features:
1. **Accounts system**: ability to create an account on the web-site and use it in the game, which allows collecting user statistics.
2. **JWT Tokens**: completely secure and fast operations via Go microservice.
3. **Containerized**: fully ready for deployment via Docker.

## Tech stack:
1. **Backend**: Golang, Python(Flask)
2. **Frontend**: Bootstrap, HTML, css
3. **Client/Game**: Python(arcade)
4. **Database**: PostgreSQL
5. **DevOps**: Dockerfile, Docker-compose
