Техническое задание на разработку веб-сервиса «Arcade Hub»
1. Общие сведения
Название проекта: Arcade Hub.
Назначение: Веб-платформа для игроков аркадной игры, обеспечивающая синхронизацию игрового прогресса, просмотр личной статистики и управление игровым контентом (скинами).

2. Цели проекта
Создание единого пространства для авторизации пользователей в игре и на сайте.

Визуализация игровых достижений (убитые враги, боссы, рекорды).

Реализация системы кастомизации (выбор скинов), влияющей на игровой процесс.

3. Функциональные требования
3.1. Информационная часть (Главная страница)
Презентация игры в стиле Steam: описание, ключевые особенности, скриншоты.

Динамические кнопки «Войти» / «Регистрация» или «Профиль» в зависимости от статуса сессии.

3.2. Система аккаунтов и безопасность
Регистрация: ввод логина, пароля, имени, фамилии и возраста.

Авторизация: вход по логину и паролю.

Безопасность: обязательное хеширование паролей перед сохранением в БД.

Валидация: * Длина пароля — не менее 8 символов.

Наличие хотя бы одной цифры в пароле.

Проверка уникальности логина.

3.3. Личный кабинет (Статистика и Кастомизация)
Отображение персональных данных игрока.

Блок статистики:

Общее количество убитых врагов и боссов.

Общее время, проведенное в игре.

Рекорд по количеству пройденных волн.

Магазин/Гардероб: выбор активного скина персонажа, который синхронизируется с игровым клиентом.

4. Технический стек
Backend: Python (Flask).

Frontend: HTML5, CSS3, Jinja2.

Библиотеки стилей: Bootstrap 5 (базовая верстка).

База данных: SQLite (через ORM SQLAlchemy).

Синхронизация: Общая база данных для игрового приложения и веб-сервера.

5. Дизайн и адаптивность
Этап 1: Использование стандартных компонентов Bootstrap для обеспечения базовой логики.

Этап 2: Внедрение уникального игрового дизайна, CSS-анимаций.

Адаптивность: Использование Media Queries для корректного отображения на мобильных устройствах.
